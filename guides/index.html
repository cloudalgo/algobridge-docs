    Guides¶

    Task-by-task instructions for setting up and running AlgoBridge. If you're new, start with Install and Your first sync, then come back here for the details.

    Connect the two ends¶

    • Connect Salesforce: create the External Client App, sign in as the integration user, and reconnect when authentication fails.
    • Connect the client database: connect your application's PostgreSQL database, grant the privileges it needs, and rotate the encryption key.

    Detect changes in Salesforce¶

    • Choose a change source: compare Composite polling, the Apex probe and the change notifier by API cost and latency, and switch between them.
    • Install the Apex bundle: deploy the bundle, assign its permission set, pair the change notifier and add its Flows.

    Sync data¶

    • Create mappings: choose objects and fields, create the tables and triggers, run the initial load, and reload a table.

    Manage access¶

    • Set up sign-in: local passwords with two-step verification, and single sign-on through Google, Microsoft or any OpenID Connect provider.
    • Manage users and roles: create the first admin, invite people, and choose between the viewer, member and admin roles.

    Operate the instance¶

    • Read the Live log: watch every query and call as it happens, and filter by level, source, process and mapping.
    • Run workers and jobs: split web and worker containers, scale workers, stop them safely, and handle dead letter jobs.
