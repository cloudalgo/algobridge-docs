        What it costs your org, before you install.

        No per-row charge, but like any integration you run yourself, AlgoBridge spends your org's Salesforce API calls. Set your numbers to see each change source's daily cost against your limit.

        Governor: 70% polling slowsGovernor: 90% polling and writes pauseEstimate. Quiet objects poll less often, so real use is lower.
